Modification
------------
One change is made to ffmpeg-core.js when it is copied into this folder
(scripts/copy-ffmpeg-core.mjs in the Clipbench source):

    - var pthreadPoolSize=32;
    + var pthreadPoolSize=Math.max(navigator.hardwareConcurrency||4,4)+16;

It sizes the WebAssembly thread pool to the machine instead of eagerly starting 32 threads (one of
32 simultaneous thread start-ups could stall and hang the engine). Nothing else is changed.
